En producciónCA-IHPBA

Gestión de Socios y Facturación Electrónica

Sistema web que reemplazó las planillas de ~300 socios del Capítulo Argentino de la IHPBA.

  • Facturación electrónica AFIP/ARCA con CAE, individual y masiva.
  • Cuotas, deuda y mora, cuenta corriente y portal del socio.
  • Cursos, dashboard y reportes para el contador.
  • .NET 8
  • EF Core
  • SQL Server
  • SOAP AFIP
  • QuestPDF
  • IIS

Choosing — Entradas y acreditación

Venta de entradas, registro y acreditación con QR para eventos de hasta 20.000 personas.

  • Cobro con Mercado Pago, directo al organizador.
  • Acreditación por QR o DNI, desde el celular o con lectora.

  • SQL Server

En producciónAsociación Argentina de Cirugía

RPQ — Registro de Prácticas Quirúrgicas

App para Windows y Android con la que los residentes de cirugía registran sus prácticas.

  • Nomenclador oficial de 525 procedimientos, digitalizado con parser propio.
  • Estadísticas personales y exportación a Excel con marca AAC.
  • 100% local: un solo .exe, sin servidor ni costo de hosting.
  • .NET 8
  • .NET MAUI
  • WinForms
  • SQLite
  • ClosedXML

También: dashboard de gestión de alquileres (contratos, aumentos por ICL/IPC, cobros) y sistemas de facturación y administración a medida para distintos clientes.
